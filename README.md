## Overview

Each rule is documented, tested, and ready to use.

## Usage

1. Open Autodesk Inventor 2025, 2026, or 2027
2. Go to Manage tab → iLogic → Add Rule
3. Click "Import" and select the rule file
4. The rule will appear in the iLogic Browser

---

## Requirements

- Autodesk Inventor 2025, 2026, or 2027
- iLogic add-in enabled
